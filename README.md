# Compiladores

Repositório da disciplina. O compilador é construído incrementalmente; cada
pasta `atvN/` contém apenas o necessário para a entrega daquela atividade.

- [`compiler/`](compiler) — o compilador CI, atualizado a cada atividade.
- [`atv2/`](atv2) — Atividade 2: o compilador CI (código em `compiler/`).
- [`atv3/`](atv3) — Atividade 3: expressões aritméticas em assembly.
