# Compiladores

Repositório da disciplina. O compilador é construído incrementalmente; cada
pasta `atvN/` contém apenas o necessário para a entrega daquela atividade.

- [`compiler/`](compiler) — o compilador, atualizado a cada atividade.
- [`atv2/`](atv2) — Atividade 2: compilador CI, autocontido.
- [`atv3/`](atv3) — Atividade 3: expressões aritméticas em assembly.
- [`atv4/`](atv4) — Atividade 4: léxico/sintático/interpretador de EC1 (código em `compiler/`).
- [`atv5/`](atv5) — Atividade 5: compilador EC1 completo com geração de código (autocontido).
- [`atv6/`](atv6) — Atividade 6: EC2, precedência e associatividade sem parênteses obrigatórios (autocontido).
- [`atv7/`](atv7) — Atividade 7: EV, variáveis com análise semântica e tabela de símbolos (autocontido).
- [`atv8/`](atv8) — Atividade 8: Cmd, comandos `if`/`while`/atribuição e comparações (autocontido).
